# Paper Reading Notes

This repository collects my reading notes and code study materials on robust principal
component analysis (RPCA), low-rank modeling, image restoration, and deep unfolding.

## Contents

- [LR3M](LR3M.md): notes on low-light enhancement with a low-rank regularized Retinex model.
- [Bayesian Learning and RPCA](Bayesian_RPCA_recommendations.md): a reading map for Bayesian learning and RPCA.
- [RoMan reproduction code](roman-robust-pca-masking-network-main/README.md): implementation and experiments for robust PCA with foreground masking.

## Repository policy

This repository contains my notes and source code only. Original paper PDFs, extracted
paper text, local Python environments, generated experiment results, and images are kept
locally and are not versioned here. Each future reading note should cite its source paper
with bibliographic information or a public DOI/arXiv link.

## Future Notes

New handwritten notes will be organized as Markdown files and added to this repository
incrementally.
